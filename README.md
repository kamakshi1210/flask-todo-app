# 🚀 Flask Todo Application

🌐 **Live Demo:** [https://flask-todo-app-7pl6.onrender.com](https://flask-todo-app-7pl6.onrender.com)

---

## 📌 Features
- Create, update, and delete Todo items.
- Built using **Flask**, **Flask-SQLAlchemy**, and **Bootstrap 5**.
- Persistent database storage using SQLite.
- Fully responsive web interface.

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask, Flask-SQLAlchemy
- **Frontend:** HTML5, Jinja2, Bootstrap 5
- **Database:** SQLite
- **Deployment:** Render, Gunicorn
